== Description ==

Gutenverse Form is a WordPress form plugin, contact form builder, block form plugin, and booking form builder for the native Block Editor. Create contact forms, booking forms, reservation forms, subscribe forms, lead forms, feedback forms, and custom WordPress forms without code.

Built for the WordPress Block Editor and Site Editor, Gutenverse Form lets you design forms visually using form blocks. Add fields, style each input, manage responsive layouts, create Form Actions from the Form Builder block, collect entries, send email notifications, and build forms that match your website design.

Use Gutenverse Form if you want a lightweight form builder that works inside the editor you already use, with admin tools for monitoring submissions, reviewing entry details, and following up with leads.

Features marked [PRO] require Gutenverse Form Pro, an active license, or the matching PRO capability on your site.

= Form Dashboard =

The Form Dashboard helps site admins monitor form activity without opening every form one by one. Review total entries, entries from the last 7 days, live form locations, tracked forms, and daily entry trends.

[PRO] Dashboard insight panels for top forms, top entry sources, recent activity, needs-attention signals, and extended range controls require Gutenverse Form Pro or the matching dashboard capability.

= Entries, Sources, And Export =

Form submissions can be saved as entries in WordPress. The entry list shows the entry title, form, source, submitted date, and quick actions for recent entries.

[PRO] Full archive access, entry search, pagination across all entries, CSV export, form filters, source filters, date filters, and older entry detail access require Gutenverse Form Pro or the matching entry-list capability.

The entry detail screen is read-only for the entry title and shows submitted field values, form information, source page links, browser information, and [PRO] payment or integration information when that data is available.

= Email Notifications And Templates =

Send admin notification emails and user confirmation emails from each connected Form Action. Emails can use static message content.

Email settings support field placeholders, dynamic recipient options, and reply-to configuration. [PRO] Template-based layouts can be saved for more polished confirmation and notification emails.

[PRO] Saving reusable designed email templates for user confirmations and admin notifications requires Gutenverse Form Pro or the matching email-template capability.

= Form Integrations [PRO] =

[PRO] Gutenverse Form integrations let forms connect with supported services. Integrations can be managed globally from the dashboard settings and connected to individual Form Actions from the Form Builder block.

When [PRO] integrations run for an entry, the entry detail screen can show triggered services, integration logs, and resubmit controls for admins.

= Spam Protection And Validation =

Gutenverse Form includes reCAPTCHA support and validation for common field types such as email, phone, number, date, required fields, checkboxes, radio buttons, and select fields.

= Daily Admin Summary =

Daily Admin Summary Email can send one daily message to the site admin email address with recent form activity, submission totals, tracked forms, and quick links back to the Form Dashboard.

== Installation ==

= From The WordPress Plugin Dashboard =

1. Go to Plugins > Add New in your WordPress dashboard.
2. Search for "Gutenverse Form".
3. Click Install Now.
4. Click Activate.
5. Open the WordPress Block Editor and search for Gutenverse Form blocks.

= Using The Upload Method =

1. Download the Gutenverse Form plugin ZIP file.
2. Go to Plugins > Add New in your WordPress dashboard.
3. Click Upload Plugin.
4. Choose the Gutenverse Form ZIP file.
5. Click Install Now.
6. Activate the plugin.

For more help, read the [Gutenverse documentation](https://gutenverse.com/docs/).

== Frequently Asked Questions ==

= Can I create booking forms and reservation forms? =

Yes. You can create booking request forms, reservation request forms, appointment inquiry forms, and other custom forms by combining form fields in the Block Editor.

= Can I create subscribe forms? =

Yes. Gutenverse Form can be used to create subscribe forms and lead generation forms. You can collect name, email, phone, and custom field data from visitors.

= Does Gutenverse Form require the Gutenberg plugin? =

No. WordPress 5.9 and newer already include the Block Editor features needed by Gutenverse Form. You do not need to install the separate Gutenberg plugin unless you want to test experimental Gutenberg features.

= Does Gutenverse Form work with the WordPress Site Editor? =

Yes. Gutenverse Form is built for the WordPress Block Editor and can be used with block themes and Site Editor workflows.

= How do I find Gutenverse Form blocks in the editor? =

Open the block inserter in the WordPress editor and search for "Gutenverse", "form", "input", or a specific field such as "email input", "checkbox", or "submit button".

= Can I save and export form entries? =

Yes. Gutenverse Form can save form submissions as entries in WordPress. [PRO] CSV export, full archive access, filtering all entries, and opening older entry details require Gutenverse Form Pro or the matching entry-list capability.

= Where do I manage Form Actions? =

Form Actions are now managed from the Form Builder block in the WordPress editor. Select the Form Builder block, then create, edit, or delete the connected Form Action from the block settings.

= Does Gutenverse Form include a dashboard? =

Yes. Go to Form > Dashboard to review submission totals, tracked forms, live locations, and daily trends. [PRO] Top forms, top entry sources, recent activity, needs-attention insights, and extended chart controls require Gutenverse Form Pro or the matching dashboard capability.

= Can I filter entries by source? =

[PRO] Entry filters require Gutenverse Form Pro or the matching filter capability. When enabled, the entry list can filter by form, source, date, and search term. Source links can open the page or location where the submission was captured.

= Can I design custom email templates? =

Yes. Form Actions can use static email content for user confirmations and admin notifications. [PRO] Saving reusable designed email templates requires Gutenverse Form Pro or the matching email-template capability.

= Can I connect forms to external services? =

[PRO] Form integrations require Gutenverse Form Pro or the matching integration capability. When enabled, integrations can send submitted form data to supported services such as Slack, Mailchimp, webhooks, Google Sheets, and other connected services.

= Does Gutenverse Form support spam protection? =

Yes. Gutenverse Form includes a reCAPTCHA block. You can use it to help protect forms from automated spam submissions.

= What should I do if a block shows unexpected or invalid content? =

After some updates, WordPress may show an "Attempt Block Recovery" button for blocks affected by older markup or styling changes. Click that button first. If the issue continues, please open a support ticket.

== Use of 3rd-Party Services ==

Gutenverse Form may connect to the following third-party services when you enable related features.

= Google reCAPTCHA =

If you add the reCAPTCHA block and configure reCAPTCHA keys, the plugin sends the reCAPTCHA response token to Google for verification. This is used only to validate the form submission and protect forms from spam.

Service endpoint: https://www.google.com/recaptcha/api/siteverify
Privacy Policy: https://policies.google.com/privacy
Terms of Service: https://policies.google.com/terms

= Optional Form Integrations [PRO] =

When you enable a [PRO] form integration, submitted form data and configured field mappings may be sent to the selected external service. Supported integration options can include WhatsApp, Telegram, Discord, Mailchimp, Slack, webhooks, GetResponse, Drip, ActiveCampaign, Kit, MailerLite, and Google Sheets, depending on the integrations available on your site.

Data is sent only for integrations you configure and enable. Review the privacy policy and terms of the external service you connect before sending visitor data to that service.

= Optional Payment Gateways [PRO] =

When you enable a [PRO] payment gateway such as LemonSqueezy, submitted payment, customer, order, and transaction data may be sent to the selected payment provider so the payment can be processed.

Data is sent only for payment gateways you configure and enable. Review the privacy policy and terms of the payment provider before collecting payment data.

= Gutenverse.com =

The Gutenverse dashboard may include optional links, template/library access, documentation, support, or newsletter subscription features from gutenverse.com. Newsletter data is sent only when you manually submit your email address.

Website: https://gutenverse.com/
Terms: https://gutenverse.com/terms-and-conditions/
